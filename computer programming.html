PART I

1. Computer Programming

1.1 Introduction

Computer programming is the process of creating instructions that tell a computer what to do.

A programmer writes these instructions using a programming language.

1.2 What is Programming?

Programming can be used to create websites, applications, games, and computer systems.

A program usually follows a series of steps. These steps form an algorithm that helps solve a problem.

  • Understand the problem
  • Plan the solution
  • Write the code
  • Test the program

1.3 Programming Languages

There are many programming languages. Each language has different features and common uses.

Language Common Use
HTML Web page structure
CSS Web page design
JavaScript Web interaction
Python Applications and automation
C++ Games and systems

1.4 Web Development

Web development focuses on creating websites and web applications.

The three basic technologies are HTML, CSS, and JavaScript.

HTML
Creates the structure of a web page.
CSS
Controls the appearance of a web page.
JavaScript
Adds interaction and behavior.

PART II

2. Introduction to HTML

2.1 What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of web pages.

HTML uses elements to organize content such as headings, paragraphs, links, images, lists, and tables.

2.2 HTML Elements

An HTML element normally contains an opening tag, content, and a closing tag.

For example:

h1 My Website

2.3 Lists and Tables

Lists organize related information, while tables display information in rows and columns.

  1. Create the HTML document.
  2. Add the page structure.
  3. Add content.
  4. Open the page in a browser.

2.4 Links and Images

Links allow users to move between web pages.

Learn more about HTML at W3Schools

Images can be displayed using the img element.

4. Basic Programming Concepts

Programs use concepts such as variables, conditions, loops, and functions.

  • Variables store information.
  • Conditions allow decisions.
  • Loops repeat instructions.
  • Functions organize reusable code.

Example of a mathematical expression:

x2 + y2

Water can be represented as H2O.

Programming is only for experts. Anyone can begin learning programming with simple concepts and practice.
